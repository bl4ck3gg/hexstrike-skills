# 恢复策略
| 错误 | 首选 | 成功概率 | 时间 |
|------|------|---------|------|
| TIMEOUT | RETRY_WITH_BACKOFF(5→60s) | 0.7 | 30s |
| TIMEOUT备 | RETRY_WITH_REDUCED_SCOPE | 0.8 | 45s |
| PERMISSION_DENIED | ESCALATE_TO_HUMAN | 0.9 | 300s |
| NETWORK_UNREACHABLE | RETRY_WITH_BACKOFF(10→120s) | 0.6 | 60s |
| RATE_LIMITED | RETRY_WITH_BACKOFF(30→300s,×1.5) | 0.9 | 180s |
| RATE_LIMITED备 | ADJUST_PARAMETERS(reduce_rate) | 0.8 | 120s |
| TOOL_NOT_FOUND | SWITCH_TO_ALTERNATIVE_TOOL | 0.7 | 15s |
| INVALID_PARAMETERS | ADJUST_PARAMETERS(use_defaults) | 0.8 | 10s |
| RESOURCE_EXHAUSTED | RETRY_WITH_REDUCED_SCOPE | 0.7 | 60s |
| AUTHENTICATION_FAILED | ESCALATE_TO_HUMAN | 0.9 | 300s |
| TARGET_UNREACHABLE | RETRY_WITH_BACKOFF | 0.6 | 90s |
| TARGET_UNREACHABLE备 | GRACEFUL_DEGRADATION | 1.0 | 5s |
| PARSING_ERROR | ADJUST_PARAMETERS | 0.7 | 20s |
| UNKNOWN | RETRY_WITH_BACKOFF | 0.3 | 45s |

## 动作枚举
RETRY_WITH_BACKOFF / RETRY_WITH_REDUCED_SCOPE / SWITCH_TO_ALTERNATIVE_TOOL / ADJUST_PARAMETERS / ESCALATE_TO_HUMAN / GRACEFUL_DEGRADATION / ABORT_OPERATION

## 选择规则
- 按 attempt 过滤可行策略
- adjusted = p × 0.9^(attempt-1)
- score = adjusted - time/1000,取最高
