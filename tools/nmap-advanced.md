# nmap-advanced
**类别**: 网络侦察
**用途**: 高级 Nmap,NSE+OS+版本

**底层命令行**:
```bash
nmap <scan_type:-sS> <target> [-p <ports>] [-T2|-T4] [-O] [-sV] [-A] [--script=<nse>]
```

失败时参考 ../recovery/tool-alternatives.md
